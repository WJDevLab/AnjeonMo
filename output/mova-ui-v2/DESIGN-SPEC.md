## 핵심 UX 원칙

- 한 화면에서 가장 중요한 행동은 하나만 Primary 버튼으로 표시한다.
- 정상 상태는 파란색, 확인 완료는 작은 초록색 표시, 운행 차단은 빨간색으로 구분한다.
- 안전 경고는 사용자가 닫고 계속 운행할 수 없도록 한다.
- 센서의 기술 정보보다 사용자가 해야 할 행동을 먼저 안내한다.
- 경고 시 전체 화면을 빨간색으로 덮지 않고 제목, 상태, 행동 영역에만 위험 색상을 사용한다.

## 센서 상태 규칙

| 상태 | 조건 | 앱 동작 |
|---|---|---|
| 연결 중 | 센서 응답 대기 | 진행 상태 표시, 출발 버튼 숨김 |
| 헬멧 미착용 | 헬멧 압력값이 착용 기준 미만 | 출발 차단, 자동 재확인 |
| 출발 가능 | 발 감지 수 2개 이하 + 헬멧 착용 확인 | 잠금 해제 버튼 활성화 |
| 인원 초과 | 발 감지 수 3개 이상 | 자동 감속 안내, 운행 지속 조작 차단 |
| 주행 중 헬멧 해제 | 헬멧 압력값이 기준 미만 | 자동 감속 안내 후 안전 정지 |
| 안전 정지 | 감속 완료 또는 정차 확인 | 재확인 및 대여 종료만 허용 |
| 복구 | 발 감지 수 2개 이하 + 헬멧 착용 확인 | 운행 재개 허용 |

> 실제 차량 제어에서는 주행 중 모터 전원을 즉시 차단하지 않고, 제어기에서 안전한 감속과 정차를 수행한 뒤 구동을 잠그도록 구현한다.

## 상태 전환

`홈 → 킥보드 선택 → QR 스캔 → 대여 확인 → 센서 연결 → 안전 확인`

- 정상: `출발 준비 → 운행 중 → 이용 완료`
- 헬멧 미착용: `안전 확인 → 출발 차단 → 자동 재확인`
- 발 3개 이상: `운행 중 → 자동 감속 → 안전 정지 → 재확인 또는 대여 종료`
